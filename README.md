- Yaprak fotoğrafı yükleme
- Bitki türü tespiti

- CNN tabanlı derin öğrenme modeli

## 🧠 Kullanılan Teknolojiler

- TensorFlow / Keras
- Streamlit
- NumPy
- Pillow
